# **Spashiny**:an interactive web platform for spatial transcriptomics-metabolomics integration and differential spatial expression pattern analysis
# Overview
![](<web/app/www/Spa_F1.png>)
We present SpaShiny, an interactive web platform incorporating SpatialMETA and River as two independent analytical modules. SpatialMETA enables interactive spatial registration and reassignment of ST and SM data, followed by three integration workflows: single-sample ST-SM integration, joint integration of multiple paired ST-SM samples, and cross-sample SM integration without paired ST data. It also supports marker feature analysis, metabolite annotation and enrichment, gene-metabolite correlations, and spatial exploration through user-defined trajectories, regions of interest, and proximity networks. River prioritizes genes associated with differential spatial expression patterns (DSEPs) across biological conditions and visualizes their spatial distributions.
